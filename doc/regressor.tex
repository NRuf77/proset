\chapter{Prototype set regressor}
\label{ch_regressors}
%
The classifier model (\ref{eq_pkx}) is constructed using marginal probabilities as baseline and indicator functions as kernels on the target space.
If we replace these by probability density functions, we obtain a locally weighted regressor.
For our implementation, we rely entirely on Gaussians.
%
\section{Definition}
\label{sec_regressor_definition}
%
To derive the regression model, we follow the notation introduced in Section \ref{sec_classifier_definition} as far as possible.
The main difference is that the random variables $Y_n$ are now real-valued and we presume w.l.o.g.\ that they have mean zero and variance one.
The implemented algorithm applies centering and scaling before fitting and reverts these when serving predictions.\par
%
As kernel on the target space, we use the univariate Gaussian density parameterized in terms of its inverse standard deviation:
%
\begin{equation}
H_u(z):\R\rightarrow(0,\infty),z\mapsto H_u(z):=\frac{u}{\sqrt{2\pi}}\exp\left(-\frac{(uz)^2}{2}\right)\label{eq_kernel_2}
\end{equation}
%
In analogy to (\ref{eq_pkx}), we estimate the density of $Y$ conditional on $X$ as
%
\begin{equation}
p(Y=y|X=x)\approx\hat{p}(y|x):=
\frac{H_1(y)+\sum_{b=1}^B\sum_{j=1}^{J_b}H_{u_b}(y-y_{s_{b,j}})w_{b,j}G_{v_b}(x-x_{s_{b,j}})}
{1+\sum_{b=1}^B\sum_{j=1}^{J_b}w_{b,j}G_{v_b}(x-x_{s_{b,j}})}
\label{eq_fyx}
\end{equation}
%
Here, we introduce an additional set of parameters $u_b>0$, $b\in\{1,\dots,B\}$, that control the smoothness of the density for each batch.
As we do not want these terms to vanish, the fitting procedure applies an $L_2$-penalty to the $u_b$ instead of elastic net regularization.
%
\begin{remark}
\begin{enumerate}
\item In case no prototypes are selected for the model, it reverts to the standard normal. 
However, batch with $v_b\equiv0$ (independent of $x$) can still capture meaningful information on $Y$, effectively updating the baseline to be non-Gaussian.
%
\item Unlike most regression algorithms that estimate a conditional mean, the proset regressor estimates the complete conditional distribution via approximation by Gaussian mixture.
It can capture properties like heteroskedasticity, multimodality, or skewness.
\end{enumerate}
\end{remark}
%
As for the classifier, we derive equations for the iterative fitting procedure in terms of non-normalized partial sums for $c\geq0$:
%
\begin{equation}
\hat{q}_c(y|x):=H_1(y)+\sum_{b=1}^c\sum_{j=1}^{J_b}H_{u_b}(y-y_{s_{b,j}})w_{b,j}G_{v_b}(x-x_{s_{b,j}})\label{eq_hatqcxy}
\end{equation}
%
The corresponding normalization factor is
%
\begin{equation}
\hat{r}_c(y|x):=1+\sum_{b=1}^c\sum_{j=1}^{J_b}w_{b,j}G_{v_b}(x-x_{s_{b,j}})\label{eq_hatrcxy}
\end{equation}
%
Thus, the estimator consisting of contributions up to batch $c$ is
%
\begin{equation}
\hat{p}_c(y|x):=\frac{\hat{q}_c(y|x)}{\hat{r}_c(y|x)}\label{eq_hatpcxy}
\end{equation}
%
In particular, $\hat{p}_0(y|x)=H_1(y)$ and $\hat{p}_B(y|x)=\hat{p}(y|x)$.\par
%
The regressor is grown from the baseline distribution by adding batches in an iterative, greedy manner.
In each step, the training data is split into a set of candidates for prototypes and a set of reference points.
To choose candidates, we adapt the strategy described in Section \ref{sec_updated_candidate_sampling}.
Instead of the probability assigned to the true class, we take the density at the target value as a measure of how well the current model fits the data.
We derive the empirical distribution of these values and use its $\beta$-quantile to separate training samples into `easy' and `hard' cases.
As for the classifier, half of the candidates for a new batch are sampled from each group.\par
%
Parameters for batch $c$ given batches up to $c-1$ are computed by minimizing a modified version of the negative log-likelihood for the reference points.
This includes sample weights that compensate for the change in relative frequency between `easy' and `hard' cases due to candidate selection, as well as penalty terms for regularization: 
%
\begin{align}
f(u_c,v_c,\{w_{c,j}\}_j|\{(x_n,y_n)\}_n)&
=-\frac{1}{N}\sum_{h=0}^1\frac{N_h}{N_h-J_{c,h}}\sum_{n\in T_{c,h}}\log(\hat{p}_c(y_n|x_n))
\label{eq_nll_regressor}\\
&+\frac{\lambda_u}{2}u_c^2\notag\\
&+\lambda_v\left(\frac{1-\alpha_v}{2}\sum_{d=1}^Dv_{c,d}^2+\alpha_v\sum_{d=1}^D|v_{c,d}|\right)\notag\\
&+\lambda_w\left(\frac{1-\alpha_w}{2}\sum_{j=1}^{J_c}w_{c,j}^2+\alpha_w\sum_{j=1}^{J_c}|w_{c,j}|\right)\notag
\end{align}
%
This is similar to the negative log-likelihood for the classifier (\ref{eq_nll_classifier}).
However, note that it already includes the differentiated re-weighting introduced in Section \ref{sec_updated_candidate_sampling}.
The following expressions still need to be defined:
%
\begin{itemize}
\item $N_h$, $h\in\{0,1\}$, are the numbers of `easy' ($h=0$) and `hard' ($h=1$) cases in the training data, i.e., $N=N_0+N_1$.
%
\item $J_{c,h}$, $h\in\{0,1\}$, are the numbers of `easy' and `hard' candidates selected.
%
\item $T_{c,h}$, $h\in\{0,1\}$, are the sets of `easy' and `hard' reference points.
%
\item $\lambda_u\geq0$ is the $L_2$-penalty weight used for smoothing the density estimator.
\end{itemize}
%
We express the partial derivatives of $f$ in terms of the partial derivatives of $\log(\hat{p}_c(y|x))$:
%
\begin{align}
\frac{\partial}{\partial u_c}\log(\hat{p}_c(y|x))&=\frac{
\frac{\partial}{\partial u_c}\sum_{j=1}^{J_c}H_{u_c}(y-y_{s_{c,j}})w_{c,j}G_{v_c}(x-x_{s_{c,j}})
}{\hat{q}_c(y|x)}\label{p_partial_u_reg}\\
&=\frac{
u_c^{-1}\sum_{j=1}^{J_c}H_{u_c}(y-y_{s_{c,j}})w_{c,j}G_{v_c}(x-x_{s_{c,j}})
}{\hat{q}_c(y|x)}\notag\\
&-\frac{
u_c\sum_{j=1}^{J_c}H_{u_c}(y-y_{s_{c,j}})(y-y_{s_{c,j}})^2w_{c,j}G_{v_c}(x-x_{s_{c,j}})
}{\hat{q}_c(y|x)}\notag\\
\frac{\partial}{\partial v_{c,d}}\log(\hat{p}_c(y|x))&=\frac{
\frac{\partial}{\partial v_{c,d}}\sum_{j=1}^{J_c}H_{u_c}(y-y_{s_{c,j}})w_{c,j}G_{v_c}(x-x_{s_{c,j}})
}{\hat{q}_c(y|x)}\label{p_partial_v_reg}\\
&-\frac{\frac{\partial}{\partial v_{c,d}}\sum_{j=1}^{J_c}w_{c,j}G_{v_c}(x-x_{s_{c,j}})
}{\hat{r}_c(y|x)}\notag\\
&=v_{c,d}\left(\frac{
\sum_{j=1}^{J_c}w_{c,j}(x_d-x_{s_{c,j},d})^2G_{v_c}(x-x_{s_{c,j}})
}{\hat{r}_c(y|x)}\right.\notag\\
&-\left.\frac{
\sum_{j=1}^{J_c}H_{u_c}(y-y_{s_{c,j}})w_{c,j}(x_d-x_{s_{c,j},d})^2G_{v_c}(x-x_{s_{c,j}})
}{\hat{q}_c(y|x)}\right)\notag\\
\frac{\partial}{\partial w_{c,i}}\log(\hat{p}_c(y|x))&=\frac{
\frac{\partial}{\partial w_{c,i}}\left(H_{u_c}(y-y_{s_{c,i}})w_{c,i}G_{v_c}(x-x_{s_{c,i}})\right)
}{\hat{q}_c(y|x)}\label{p_partial_v_reg}\\
&-\frac{\frac{\partial}{\partial w_{c,i}}\left(w_{c,i}G_{v_c}(x-x_{s_{c,i}})\right)
}{\hat{r}_c(y|x)}\notag\\
&=\frac{H_{u_c}(y-y_{s_{c,i}})G_{v_c}(x-x_{s_{c,i}})}{\hat{q}_c(y|x)}
-\frac{G_{v_c}(x-x_{s_{c,i}})}{\hat{r}_c(y|x)}\notag
\end{align}
%
Thus, the partial derivatives of the objective function itself on the first orthant are:
%
\begin{align}
\frac{\partial}{\partial u_c}f(u_c,v_c,\{w_{c,j}\}_j|\{(x_n,y_n)\}_n)&=
-\frac{1}{N}\sum_{h=0}^1\frac{N_h}{N_h-J_{c,h}}\sum_{n\in T_{c,h}}\frac{\partial}{\partial u_c}\log(\hat{p}_c(y_n|x_n))
\label{eq_l_partial_u_reg}\\
&+\lambda_uu_c\notag\\
\frac{\partial}{\partial v_{c,d}}f(u_c,v_c,\{w_{c,j}\}_j|\{(x_n,y_n)\}_n)&=
-\frac{1}{N}\sum_{h=0}^1\frac{N_h}{N_h-J_{c,h}}\sum_{n\in T_{c,h}}\frac{\partial}{\partial v_{c,d}}\log(\hat{p}_c(y_n|x_n))
\label{eq_l_partial_v_reg}\\
&+\lambda_v((1-\alpha_v)v_{c,d}+\alpha_v)\notag\\
\frac{\partial}{\partial w_{c,j}}f(u_c,v_c,\{w_{c,j}\}_j|\{(x_n,y_n)\}_n)&=
-\frac{1}{N}\sum_{h=0}^1\frac{N_h}{N_h-J_{c,h}}\sum_{n\in T_{c,h}}\frac{\partial}{\partial w_{c,j}}\log(\hat{p}_c(y_n|x_n))
\label{eq_l_partial_w_reg}\\
&+\lambda_w((1-\alpha_w)w_{c,j}+\alpha_w)\notag
\end{align}
%
Apart from the differences outlined above, the proset regressor is fitted in the same way as the classifier.
%
\subsection{Inference}
\label{sec_inference}
%
Most regression algorithms only estimate the conditional mean, often under the assumption of homoskedastic Gaussian residuals.
Proset approximates the conditional density as a Gaussian mixture, which allows us to infer several quantities of interest from a single model.
In particular, we gain quantile regression `for free', although we need to ensure efficient computation.\par
%
In this section, we consider how to derive relevant quantities from a Gaussian mixture.
We disregard the precise form of the model to simplify notation and just presume a conditional density of the form
%
\begin{equation}
m(y):=\sum_{j=1}^J\alpha_jH_{u_j}(y-y_j)\label{eq_mixture_pdf}
\end{equation}
%
with weights $\alpha_j\in(0,1)$, $\sum_{j=^1}^J\alpha_j=1$, inverse standard deviations $u_j>0$, and centers $y_j\in\R$.\par
%
As the standard normal density is available as a mathematical function, typically via a look-up table with interpolation, $m(y)$ can be efficiently evaluated at arbitrary points.
The same goes for the cumulative distribution, which can be expressed via the standard normal CDF $\Phi$ as
%
\begin{equation}
M(y):=\sum_{j=1}^J\alpha_j\Phi(u_j(y-y_j))\label{eq_mixture_cdf}
\end{equation}
%
The conditional mean and variance are likewise easy to derive from the additive form.
Let $Y$ be a random variable with density $m(y)$, then
%
\begin{align}
\E(Y)&=\sum_{j=1}^J\alpha_jy_j&
\Var(Y)&=\E(Y^2)-\E(Y)^2=\sum_{j=1}^J\alpha_j\left(u_j^{-2}+y_j^2\right)-\E(Y)^2\label{eq_moments}
\end{align}
%
Unfortunately, there is no closed-form expression for the quantile function, which is the inverse of (\ref{eq_mixture_cdf}).
We approximate it by constructing a sequence of nested intervals via linear interpolation.
Let $q\in\R$ denote the desired quantile of the mixture and $p\in(0,1)$ the associated probability, i.e., $M(q)=p$.
Using the corresponding quantile $\tilde{q}$ of the standard normal distribution, we derive bounds on $q$ as
%
\begin{align}
l_q&:=\min\{y_j+\tilde{q}u_j^{-1}:j\in\{1,\dots,J\}\}&
u_q&:=\max\{y_j+\tilde{q}u_j^{-1}:j\in\{1,\dots,J\}\}
\label{eq_quantile_bounds}
\end{align}
%
By definition, $\Phi(u_j(l_q-y_j))\leq p$ for all $j$, so that $M(l_q)\leq p\iff l_q\leq M^{-1}(p)=q$.
A similar argument shows that $u_q\geq q$.
